# Notice

`2D-character-create` is a game-character-oriented adaptation inspired by the public OpenAI `hatch-pet` skill workflow.

Main adaptation goals:

- JSON-configurable sprite dimensions.
- Arbitrary animation actions.
- Protagonist, enemy, NPC, and boss roles.
- Godot-friendly output metadata.
- Preserve the original hatch-pet design idea of canonical base reference, grounded row generation, deterministic scripts, QA contact sheets, and targeted repair.

This package is not an official OpenAI curated skill.
